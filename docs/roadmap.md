# 9 月 30 日前的交付计划

目标：完成一个可以运行、测试和测量的 C++23 协程 TCP 服务框架。所有性能表述以实测数据为准。

## 9 月 28 日：单线程闭环

- [x] Boost.Context 有栈 Fiber 与单线程 Scheduler。
- [x] epoll IOManager、读写事件与取消。
- [x] 单调时钟定时器、Fiber 睡眠及读写超时。
- [x] 非阻塞 TCP 监听器和 echo 示例。
- [x] socketpair 与回环 TCP 集成测试。

## 9 月 29 日：并发与生命周期

- [x] 多线程调度器：明确每个 Fiber 的归属线程，不跨线程恢复栈。
- [x] 每个 I/O 线程独立 epoll；跨线程投递使用 eventfd 唤醒。
- [x] 服务停止时取消监听和连接等待，并等待工作任务退出。
- [x] 1000 并发连接、连接断开、超时和停止的回归测试；连续 100 万次回显资源检查。

## 9 月 30 日：性能证据与交付

- [x] 固定测试环境、构建类型、连接数、消息大小和请求次数。
- [x] 记录 echo 吞吐量、延迟分位数、服务端 CPU 时间和内存峰值。
- [ ] 分析热点与资源上限，修复实际测得的瓶颈。
- [x] 更新 README：架构图、运行命令、测试结果和已知限制。

优先顺序：可正确停止的完整请求链路 → 可复现的并发测试 → 有数据支持的优化。若多线程实现未完成，不把单线程结果称为多核性能。
